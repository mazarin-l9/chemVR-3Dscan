scan2png（スキャン → 点群PNG）

1. スキャンのファイルを選ぶ

対応: PLY（点群・メッシュ・3D Gaussian Splatting）、SPZ、GLB、OBJ（.mtl と画像を一緒に選ぶか、ZIP のまま）、FBX（ZIP 可）、USDZ（簡易）

3. 確認して保存

指でドラッグすると回せます（ワールドで正面から見た向きから始まります）。

4. GitHub に直接アップロード（任意・いちばん速い）

GitHub の「Fine-grained token」（このリポジトリの Contents: Read and write だけ）を貼ると、このページから scans/slotN.png に上書きアップロードします。トークンはこの端末にだけ保存されます。

5. 公開された画像を確かめる

ワールドで読む前に、URL の画像が壊れていないか（再圧縮・縮小されていないか）と題名を確かめます。

変換はすべてこの端末の中で行います（ファイルはどこにも送りません。GitHub へのアップロードを押したときだけ送ります）。
